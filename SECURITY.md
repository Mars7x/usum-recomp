# Security

This project is experimental and has no supported production release.
Game dumps and capture files are untrusted inputs; bugs in parsing or
runtime handling should be reported without attaching the original data.

Use GitHub's **Security → Report a vulnerability** private reporting option
for security issues. Include a minimal synthetic reproducer when possible.
Do not open public issues containing credentials, private files, or game data.
If a credential is exposed, revoke it with its provider before reporting it.
